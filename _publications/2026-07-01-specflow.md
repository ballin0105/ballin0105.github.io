SpecFlow is a training-free framework for efficient vision-language model inference. It replaces destructive visual-token pruning with conservative token condensation by combining spectral heat-flow diffusion on a kNN token graph, coverage-aware quadtree token allocation, and lightweight sink-token aggregation.
